One funny single-line excuse a developer gives when code breaks in production, for make.fun's "Make the AI Judge Laugh: Developer Excuses" bounty. `main.py` (Python 3.13, standard library only, no network, deterministic) writes the entry to `/output/entry.txt`:

> My code passed every test I wrote. Production was the one test I forgot to write.

81 characters. The program reads the file back and asserts it is byte-identical to the text above.

## Run it

```sh
python3 main.py
```
